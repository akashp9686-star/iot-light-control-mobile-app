# Limitations and Future Scope

## Current limitations

- Operation depends on Wi-Fi connectivity and the Blynk cloud service.
- The repository has not yet been physically tested; real-world behaviour is not claimed.
- The default demonstration controls one LED output only.
- The implementation does not include local physical buttons or offline control.
- Blynk service features and dashboard labels may change over time.
- A relay module's trigger polarity and electrical compatibility depend on its exact model.

## Future improvements

- Add local manual override.
- Add device status feedback to the app.
- Add reconnection diagnostics and non-blocking connection management.
- Add multiple independently controlled outputs.
- Add an appropriately isolated and certified relay enclosure for qualified installation where a real appliance is required.
- Add genuine photographs, test records and a short demonstration video after physical validation.
