## Expected behaviour

For the LED demonstration, a Blynk Button command of 1 on Virtual Pin V0 should cause the firmware to set D1 (GPIO5) HIGH; a command of 0 should set D1 LOW. The LED is expected to follow those states when wired with the 220 Ω series resistor.

These are expected outcomes from the implementation, not recorded experimental results.
