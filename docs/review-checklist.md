# Repository Review Checklist

Use this checklist before sharing the repository for assessment.

## Documentation and source

- [x] README describes the objective, hardware inventory, firmware mapping, setup and safety.
- [x] Source code uses Blynk Virtual Pin V0 to control NodeMCU D1 (GPIO5).
- [x] Example configuration file contains placeholders, not credentials.
- [x] Local credentials file is ignored by Git.
- [x] Wiring and architecture documentation are included.
- [x] Manual test plan and results-report template are included.
- [ ] Confirm the source code matches the exact hardware actually assembled.
- [ ] Build the firmware with the project's real Blynk configuration.

## Physical project evidence

- [ ] Add genuine photograph of the assembled circuit.
- [ ] Add genuine Blynk dashboard screenshot with secrets hidden.
- [ ] Add genuine output ON and OFF photographs.
- [ ] Record actual test date, observations and results.
- [ ] If a relay is used, record exact module model and verify electrical compatibility.

## Submission checks

- [x] Repository is public.
- [ ] Review all files for personal information, Wi-Fi passwords and Blynk tokens.
- [ ] Confirm the final README links work.
- [ ] Confirm the project has been physically completed and tested before describing it as completed to the evaluator.

A checked documentation item means the file exists in the repository. It does not mean a physical test has passed.
