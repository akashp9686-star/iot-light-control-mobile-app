# Objectives

1. Connect an ESP8266 NodeMCU to a Wi-Fi network.
2. Create a Blynk IoT template and device.
3. Configure a mobile Button widget using Virtual Pin V0.
4. Receive the button state in the ESP8266 firmware.
5. Control an LED connected to D1 (GPIO5) through a 220 Ω resistor.
6. Display connection and output status through the Serial Monitor.
7. Document setup, wiring, testing, limitations and safety.

## Expected outcome

When the user switches the Blynk Button ON, the firmware sets D1 HIGH and the LED should illuminate. When switched OFF, D1 is set LOW and the LED should turn off. This expected behaviour must be verified on the assembled circuit before being reported as a test result.
