# Abstract

This project demonstrates remote control of a low-voltage light output using an ESP8266 NodeMCU and the Blynk IoT platform. A user operates a Button widget in the Blynk mobile application. The device receives the command through the Blynk cloud connection and changes the digital state of NodeMCU pin D1 (GPIO5), which drives an LED through a current-limiting resistor.

The design introduces basic concepts of Wi-Fi-enabled embedded systems, cloud-connected device control, virtual datastreams and mobile dashboards. The default demonstration uses an LED rather than a household electrical appliance to keep initial testing within a low-voltage prototype environment.

This abstract describes the intended system. Successful operation must be established through the testing procedure and genuine project evidence.
